# Autoderm – AI Dermatology API

Autoderm is a white-label REST API for AI-powered skin-image analysis. It accepts an image via HTTP POST and returns ranked skin-condition predictions with ICD-10 codes, medical and layman's names, and links, covering 70+ conditions. CE-marked and built for telemedicine, pharmacy, and digital health platforms.
